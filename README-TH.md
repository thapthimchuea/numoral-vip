# Numoral VIP — สถิติหวยลาว VIP (PWA)

แอปสถิติหวยลาว VIP ที่ต่อยอดจาก Numora ใช้หน้าตาและสูตรชุดเดียวกัน แต่ปรับให้เข้ากับหวยลาว VIP
แอปนี้วิเคราะห์สถิติอย่างเดียว ไม่รับแทงและไม่รับเงินใดๆ

## มีอะไรบ้าง

| ไฟล์/โฟลเดอร์ | หน้าที่ |
|---|---|
| `index.html`, `app.js`, `vendor.js`, `styles.css` | ตัวแอป (`app.js` ฝังผลย้อนหลังไว้ 2,032 งวด: 12 มี.ค. 2564 – 17 พ.ย. 2569) |
| `manifest.json`, `sw.js`, `icons/` | ทำให้ติดตั้งลงมือถือและเปิดออฟไลน์ได้ (ไอคอนมีป้าย VIP สีทอง) |
| `data/draws.json` | งวดใหม่หลัง 17 พ.ย. 2569 ที่ระบบดึงมาให้อัตโนมัติ |
| `scripts/update-draws.mjs` | สคริปต์ดึงผลงวดใหม่ |
| `.github/workflows/update-draws.yml` | ตั้งเวลาให้ GitHub รันสคริปต์ทุกคืน |
| `friends/` | ลิงก์สำหรับเพื่อน (ต้องใช้รหัสเชิญ) ดู `friends/README-TH.md` |

## ต่างจาก Numora ตรงไหน

- **โมเดลข้อมูล:** เลข 5 หลัก · 3 ตัวบน = 3 หลักท้าย · 2 ตัวบน = 2 หลักท้าย · 2 ตัวล่าง = หลักที่ 2–3
- **งวด:** ออกทุกวัน 21:30 น. การ์ดหน้าแรกนับถอยหลังทุกวัน
- **ตัวกรอง:** ช่วงย้อนหลัง 30/100/365 งวด/ทั้งหมด, วันในสัปดาห์, เดือน (ตัดตัวกรองวันที่ 1/16 ออก)
- **สูตร:** ใช้สูตรเดิมครบทั้ง 2 ตัว / 3 ตัวบน / 3 ตัวโต๊ด (ตัด "ท้าย 3 ตัว" ออก เพราะหวยลาว VIP ไม่มี)
- **เพิ่ม:** การ์ด "ความเอนเอียงของแต่ละหลัก" ทดสอบ Chi-square แยกทีละหลักทั้ง 5 หลัก
- **ตัดออก:** เลขเด็ดแม่จำเนียร, ตรวจสลาก/สลากของฉัน (เป็นของหวยรัฐบาลไทย)
- **ข้อมูลในเครื่องแยกจาก Numora:** แม้อยู่โดเมนเดียวกัน (`thapthimchuea.github.io`) เลขโปรด บันทึก และค่าใช้จ่ายก็ไม่ปนกัน

## ขั้นที่ 1: สร้าง repository ใหม่บน GitHub

1. ที่ github.com กด **+ → New repository** ตั้งชื่อ **`numoral-vip`** เลือก **Public** แล้วกด **Create repository**
   (ถ้าตั้งชื่ออื่น ต้องแก้ `DATA_ORIGIN` ใน `friends/src/worker.js` ให้ตรง)
2. อัปโหลดไฟล์ด้วย git จากโฟลเดอร์ `C:\numoral-vip` (แบบเดียวกับที่ใช้กับ numora):

   ```
   cd C:\numoral-vip
   git init -b main
   git add .
   git commit -m "Numoral VIP v1"
   git remote add origin https://github.com/thapthimchuea/numoral-vip.git
   git push -u origin main
   ```

   หรือจะลากไฟล์ขึ้นเว็บ GitHub ก็ได้ แต่ต้องได้โฟลเดอร์ `.github` ด้วย (ซ่อนอยู่ใน Windows Explorer)
3. ไปที่ **Settings → Pages** · Source: **Deploy from a branch** · Branch: **main** / **(root)** → **Save**
4. รอ 1–3 นาที แอปจะอยู่ที่ `https://thapthimchuea.github.io/numoral-vip/`

## ขั้นที่ 2: เปิดระบบดึงผลอัตโนมัติ

1. **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions** แล้วกด Save
2. ไปแท็บ **Actions** → เลือก **Update Lao VIP draws** → กด **Run workflow** หนึ่งครั้งเพื่อทดสอบ
3. เปิด log ของรอบนั้น บรรทัดสุดท้ายควรเป็น `ล่าสุดเดิม ... · เพิ่ม N งวด`
   - ถ้ามีบรรทัด `ผิดพลาด raakaadee: ...` หรือ `ผิดพลาด ตรวจหวย.com: ...` แปลว่าเปิดเว็บนั้นไม่ได้ หรือหน้าเว็บเปลี่ยนรูปแบบ (ส่ง log มาให้ช่วยดูได้)

ตารางเวลา (เวลาไทย): 21:40, 21:55, 22:15, 22:45, 23:30 และสำรอง 08:10 น. ของวันถัดไป
GitHub อาจรันช้ากว่าเวลาที่ตั้งไว้ 5–30 นาทีในช่วงที่คนใช้เยอะ

**กติกาการบันทึกผล:** ดึงจาก raakaadee.com แล้วเทียบกับ ตรวจหวย.com
- ตรงกัน → บันทึก
- ไม่ตรงกัน → ไม่บันทึก รอรอบถัดไป
- มีแค่แหล่งเดียว → บันทึกเมื่ออีกแหล่งเปิดไม่ได้ หรืองวดนั้นผ่านไปแล้วเกิน 1 วัน

ทุกแถวที่อ่านได้ต้องผ่านการตรวจตัวเอง (3 ตัวบนและ 2 ตัวล่างที่เว็บแสดง ต้องตรงกับเลข 5 หลัก) ไม่งั้นจะถูกทิ้ง

> GitHub จะหยุดงานตั้งเวลาถ้า repo ไม่มีความเคลื่อนไหว 60 วัน แต่หวยลาว VIP ออกทุกวันและมี commit ทุกวันอยู่แล้ว

## ขั้นที่ 3: ติดตั้งลงมือถือ

- **Android (Chrome):** เปิดลิงก์ → แถบ "ติดตั้ง" ในแอป หรือเมนู ⋮ → ติดตั้งแอป
- **iPhone (Safari):** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

ติดตั้งคู่กับ Numora ได้ ไอคอน Numoral VIP มีป้าย VIP สีทองให้แยกออก

## อัปเดตแอปเวอร์ชันใหม่

แก้ไฟล์แล้วเปลี่ยน `const VERSION = 'v1';` ใน `sw.js` เป็น `'v2'` (เพิ่มทุกครั้ง) แล้ว push
มือถือจะได้เวอร์ชันใหม่ตอนเปิดแอปครั้งถัดไป (บางครั้งต้องปิด-เปิด 2 รอบ)

## ทดสอบตัวแยกข้อมูลในเครื่อง (ไม่ต้องต่อเน็ต)

```
node scripts/update-draws.mjs --test
```

ข้อมูลและตัวเลขทั้งหมดเป็นการคำนวณทางสถิติเพื่อความบันเทิงและการศึกษาเท่านั้น ไม่ได้การันตีผลรางวัล
