# Numoral Laos — สถิติหวยลาวพัฒนา (PWA)

แอปสถิติหวยลาวพัฒนา (สลากพัฒนา สปป.ลาว) เดิมคือ Numoral VIP ที่เปลี่ยนมาใช้หวยลาวพัฒนา
ลิงก์และระบบรหัสเชิญยังเป็นของเดิม (repo `numoral-vip`, Worker `numoral-vip-friends`, รหัสขึ้นต้น `VIP-`) เพื่อให้รหัสของเพื่อนใช้ต่อได้
แอปนี้วิเคราะห์สถิติอย่างเดียว ไม่รับแทงและไม่รับเงินใดๆ

## โมเดลข้อมูล

- เลขรางวัล 6 ตัว · **3 ตัวบน** = 3 ตัวท้าย · **2 ตัวบน** = 2 ตัวท้าย · **2 ตัวล่าง** = 2 ตัวแรกของเลขท้าย 4 ตัว (หลักที่ 3–4 ของเลข 6 ตัว)
- ออกวันจันทร์–ศุกร์ เวลา 20:00 น. (ตั้งแต่ 2 เม.ย. 2569 · ก่อนหน้านั้นออก จันทร์ พุธ ศุกร์) และงดในวันหยุดราชการลาว
- ข้อมูลย้อนหลังในแอป 871 งวด (17 พ.ค. 2564 – 19 พ.ย. 2569) รวมจาก raakaadee.com, ข่าวสด และ ผลหวย.com
  - ช่วงที่ซ้อนกัน (501 งวด) ตรงกันทุกงวด ไม่มีขัดกัน
  - ตัดงวด 31 มี.ค. 2569 ของ raakaadee ออก (เลขซ้ำกับวันที่ 2 เม.ย. และวันนั้นไม่มีการออกรางวัล)
  - 2 งวด (4 และ 6 พ.ค. 2569) รู้แค่เลขท้าย 4 ตัว จึงแสดง 2 หลักแรกเป็น "·"

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `app.js`, `vendor.js`, `styles.css` | ตัวแอป |
| `manifest.json`, `sw.js`, `icons/` | ติดตั้งลงมือถือและเปิดออฟไลน์ (ไอคอนมีป้าย LAOS) |
| `data/draws.json` | งวดใหม่หลัง 19 พ.ย. 2569 ที่ระบบดึงมาให้อัตโนมัติ |
| `data/picks.json` | ชุดลุ้น 10/20 ตัวที่ล็อกไว้ก่อนผลออกทุกงวด |
| `scripts/update-draws.mjs` | ดึงผลงวดใหม่ (ข่าวสด เทียบกับ ผลหวย.com) |
| `scripts/lock-picks.mjs` | ล็อกชุดลุ้นของงวดถัดไป (ข้ามวันเสาร์–อาทิตย์) |
| `.github/workflows/update-draws.yml` | ตั้งเวลาดึงผลและล็อกชุดลุ้น |
| `.github/workflows/deploy-friends.yml` | deploy ลิงก์สำหรับเพื่อนขึ้น Cloudflare |
| `friends/` | ลิงก์สำหรับเพื่อน (รหัสเชิญ) |

## ระบบดึงผลอัตโนมัติ

เวลา (ไทย): จันทร์–ศุกร์ 20:40, 20:55, 21:15, 21:45, 22:30 · ทุกวัน 08:10 (สำรอง) · ล็อกชุดลุ้นสำรอง 11:20, 15:50, 18:20

กติกา: เทียบเลขท้าย 4 ตัวจากข่าวสดกับผลหวย.com
- ตรงกัน → บันทึก (เก็บเลข 6 ตัวถ้ามี)
- ไม่ตรงกัน → ไม่บันทึก รอรอบถัดไป
- มีแหล่งเดียว → บันทึกเมื่ออีกแหล่งเปิดไม่ได้ หรือเป็นงวดของวันก่อนหน้า

## อัปเดตแอป

แก้ไฟล์แล้วเปลี่ยน `const VERSION` ใน `sw.js` แล้ว push · ทดสอบตัวแยกข้อมูล: `node scripts/update-draws.mjs --test`
